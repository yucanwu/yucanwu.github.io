My contribution

  • Developed the vessel configuration using dual-propeller differential steering and dual rudders.
  • Selected major components and reviewed the Autodesk Fusion model.
  • Assisted with concrete casting using 3D-printed inner and outer molds.
  • Designed component mounting and electrical wiring.
  • Programmed rudder control on an ESP32 using Python, receiving PWM input and generating PWM commands for the servos.
